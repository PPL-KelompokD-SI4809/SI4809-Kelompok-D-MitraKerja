2. Apa Saja yang Dikerjakan?
================================================================

A. Membuat Middleware `EnsureUserHasRole`
   - File baru: `app/Http/Middleware/EnsureUserHasRole.php`
   - Middleware menerima parameter role (satu atau lebih) dan
     memeriksa kolom `role` pada User yang sudah ter-autentikasi.
   - Jika role tidak sesuai, server mengembalikan HTTP 403 Forbidden.
   - Contoh penggunaan: `->middleware('role:job_seeker')`

B. Mendaftarkan Middleware Alias di `bootstrap/app.php`
   - Menambahkan alias `'role' => EnsureUserHasRole::class` pada
     bagian `withMiddleware()` sesuai pola Laravel 12.

C. Melindungi Route yang Memerlukan Login
   - Route `/profil`, `/profile` (GET/PUT/PATCH) sekarang berada
     di dalam group `Route::middleware(['auth'])`.
   - Pengguna tanpa login otomatis diarahkan ke halaman `/masuk`.

D. Membatasi Route Berdasarkan Peran
   - Route khusus Pencari Kerja (job_seeker):
     * `/dashboard/pencari-kerja` → Dashboard pencari kerja
     * `/lowongan` → Daftar lowongan pekerjaan
     Dilindungi oleh `middleware(['auth', 'role:job_seeker'])`.

   - Route khusus Perusahaan (employer):
     * `/dashboard/perusahaan` → Dashboard perusahaan
     * `/kelola-lowongan` → Kelola lowongan pekerjaan
     Dilindungi oleh `middleware(['auth', 'role:employer'])`.

E. Pemeriksaan Server-Side (Bukan Hanya Menyembunyikan Menu)
   - Proteksi dilakukan di level middleware server, bukan hanya
     menyembunyikan elemen menu di frontend.
   - Akses langsung via URL (ketik di address bar) tetap diperiksa
     dan ditolak jika role tidak sesuai.

F. Membuat View Dashboard
   - `resources/views/dashboard/job-seeker.blade.php`
   - `resources/views/dashboard/employer.blade.php`

- Tidak ada perubahan pada Model User, Enum UserRole, atau migrasi
  database — semua menggunakan struktur dari SKM-36 milik Rama.
