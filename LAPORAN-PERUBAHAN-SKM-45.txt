  maupun konstanta/helper terkait peran pengguna. Password sudah menggunakan cast 'hashed'.
- Migration (`database/migrations/`):
  Tabel 'users' hanya mendefinisikan kolom id, name, email (unique), email_verified_at,
  password, remember_token, dan timestamps. Belum ada kolom 'role'.
- Validasi Server-Side:
  Belum terdapat Form Request khusus untuk pembuatan/penyimpanan akun pengguna.
- Controller & Route:
  Hanya ada `Controller.php` dan `routes/web.php` dasar (hanya memuat GET /).

  Hanya ada `resources/views/welcome.blade.php`. Belum ada form view pendaftaran akun
  di branch ini. Sesuai aturan keras, file view/desain TIDAK DIUBAH sama sekali.
- Testing Awal:
  Hanya ada 2 test bawaan (ExampleTest) dengan status lulus.

Perubahan yang Dilakukan:
- Menambahkan Enum `app/Enums/UserRole.php` untuk standarisasi peran pengguna:
  `job_seeker` (Pencari Kerja), `employer` (Perusahaan), dan `user` (Pengguna).
- Membuat file migration baru:
  `database/migrations/2026_11_17_000001_add_role_to_users_table.php`
  yang menambahkan kolom 'role' (string, default: 'user') setelah kolom 'password',
  lengkap dengan fungsi rollback `dropColumn('role')`.
- Memperbarui `app/Models/User.php`:
  Menambahkan 'role' ke `$fillable`, menambahkan konstanta ROLE_JOB_SEEKER, ROLE_EMPLOYER,
  ROLE_USER, serta helper `roleEnum()`, `isJobSeeker()`, dan `isEmployer()`.
  Cast `'password' => 'hashed'` dan `$hidden = ['password', 'remember_token']` dipertahankan.
- Memperbarui `database/factories/UserFactory.php`:
  Menetapkan nilai default role ke `job_seeker`, serta menambahkan state helper
  `employer()` dan `jobSeeker()`.
- Membuat Form Request `app/Http/Requests/StoreUserRequest.php`:
  Menerapkan aturan validasi server-side lengkap dengan pesan berbahasa Indonesia:
  * name: required|string|max:255
  * email: required|string|email:rfc|max:255|unique:users,email
  * password: required|string|min:8|confirmed (jika konfirmasi disertakan)
  * role: required|string|in:[valid roles]
- Membuat Controller `app/Http/Controllers/UserController.php`:
  Menyimpan akun baru hanya menggunakan `$request->validated()` dalam `DB::transaction(...)`.
  Password otomatis di-hash satu kali oleh cast Eloquent (tidak di-hash ganda).
  Mendukung respons JSON (201) untuk API dan Redirect Back untuk form web.
  Menangani exception dengan DB rollback, error logging, dan respons error standar.
- Menambahkan route di `routes/web.php`:
  * POST `/users` -> UserController@store (name: users.store)
  * POST `/register` -> UserController@store (name: register)
- Membuat Feature Test komprehensif di `tests/Feature/UserAccountStorageTest.php`
  mencakup 7 skenario wajib (10 test case, 61 assertion lulus).

  melalui `$request->validated()`.
